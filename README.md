# number-guessing-game

a really simple command game i made to get back into python

## how it works
1. the program generates a number from 1-100.
2. the player inputs their guess.
3. the program outputs feedback like "too high" or "too low" until the correct number is guessed

## what i learned
* working with user input
* using conditionals (`if/else`) to control game logic
* using loops (`while`) to keep the game running until won
* generating random numbers
